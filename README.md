# 🌿 Pondok Embun — Cozy Village Sim

> Game life-simulation bergaya *cozy village sim* yang berjalan penuh di browser dalam **SATU file HTML**. Tanpa library eksternal, tanpa aset gambar/audio eksternal, tanpa server. Semua karakter, item, dan nama adalah **karya orisinal**.

---

## 🎮 Cara Menjalankan

### Cara tercepat (offline)
1. Simpan file `index.html` di komputer/HP kamu.
2. Klik dua kali (atau buka dengan browser pilihan).
3. Selesai. Langsung main.

### Cara via server lokal (opsional)
```bash
# Python 3
python -m http.server 8000

# Node.js (jika punya npx)
npx serve
